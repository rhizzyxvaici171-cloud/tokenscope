Security checks

        
    
      
    

    
    

    
    
  
    

  
    
    
    What this checks for
    
    
      
      
    • alg: none — a critical, well-documented JWT vulnerability where a server accepts unsigned tokens if it doesn't strictly validate the algorithm.
      • 
      
    • Missing or long-lived expiry — tokens with no exp claim, or an expiry far in the future, widen the window an attacker can use a stolen token.
      • 
      
    • Weak or unusual algorithms — flags algorithms known for implementation pitfalls, like HS256/RS256 confusion attacks.
      • 
      
    • Expired tokens — tells you plainly whether the token is currently valid by time, though this app has no way to check server-side revocation.
      •
